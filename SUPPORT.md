# Support

Support is provided through
[GitHub Issues](https://github.com/Pigbibi/GoogleVoicePulseBot/issues) on a
best-effort basis.

Before opening an issue, check the README, search existing issues, run the
workflow manually, and inspect the failing step. Include the workflow run URL,
expected result, actual result, and a redacted log excerpt.

Do not include Gmail credentials, App Passwords, gateway addresses, or private
account details. Delivery and number-retention decisions are controlled by
external services and cannot be guaranteed by this project.

Follow [SECURITY.md](SECURITY.md) instead of opening a normal issue for a
vulnerability or credential exposure.
